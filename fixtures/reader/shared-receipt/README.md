Ví dụ mẫu của Spec Format v1: một sản phẩm giả "Saved filters" đủ để chạy `spec-lint` và `render` mà không viết code. Không phải sản phẩm thật.

## Cấu trúc

| Thư mục | Loại tài liệu | Dùng để |
|---|---|---|
| `intake/` | intake | BRD gốc của PO |
| `contract/` | contract | Feature contract và các amendment |
| `prd/` | prd | Bảng yêu cầu REQ |
| `us/` | us-index, us | Mỗi story một file |
| `readable/` | release, epic | Lớp đọc cho người, sinh từ epic-map |
| `ux/` | ux, wireframe-index | Flow, màn hình, wireframe |
| `delivery/` | build | Wave spec của người dựng |
| `decisions/` | decisions | Sổ quyết định |
