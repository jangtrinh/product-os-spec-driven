# Changelog

All notable changes to this kit are documented here. This project uses the Keep a Changelog format.

## [2.3.0] - 2026-10-15

### Added

- Established the public, source-available kit-only distribution under the PRODUCT:OS Spec Driven name.
- Added capability skill IDs and migration support for the current command surface.
- Added an explicit package allowlist for distributable kit content.
- Added the monochrome reader theme and generated brand cube.
- Added the PolyForm Noncommercial 1.0.0 license and public-content hygiene guard.

### Changed

- The public repository history begins at version 2.3.0.

## [2.2.2] - 2026-10-13

- Allowed manual review after an amendment.
- Made shipped tooling run from an installed project context.
- Published the 2.2.2 kit release.

## [2.2.1] - 2026-10-13

- Preserved earlier gate records when later-stage ledgers append.
- Treated post-gate edits as PO amendments instead of silently replacing approved work.
- Improved repair re-entry for manual review and provider failures.
- Kept configured agent commands and owner-controlled keys stable during initialization and upgrade.
- Added the product reader treatment and copy-for-AI support.
- Improved project context handling and runner next-command guidance.

## [2.2.0] - 2026-10-13

- Added safe loading of PO-prepared source and UI context.
- Kept ignored context visible instead of dropping it silently.
- Bound loaded context to stage inputs, snapshots, review bindings, and censuses.
- Added context-intake guidance and command reference material.
- Improved upgrade preservation for project-owned configuration and answers.
- Updated the kit installation command for the renamed public repository.
- Kept historical snapshots and frozen prompt declarations stable through the release.

## [2.1.0] - 2026-10-12

- Added mandatory wireframe and prototype stages to the default flow.

## [2.0.2] - 2026-10-12

- Expanded the PO guide into the primary operating reference.
