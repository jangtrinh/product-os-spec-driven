# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: participate respectfully, welcome good-faith contributors, avoid harassment and discrimination, and help maintain a constructive technical community. Maintainers may remove, edit, reject, or otherwise respond to behavior that violates these standards.

To report an incident privately, use this repository's [private reporting channel](https://github.com/jangtrinh/product-os-spec-driven/security/advisories/new). Reports will be handled with care and shared only as needed to investigate and respond.
